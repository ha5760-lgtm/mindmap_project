===== 변환 방법 =====

각 파일을 다음 구조로 변환:

<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>[제목]</title>

  <!-- 필요한 CDN 라이브러리 -->
  <script src="https://cdn.tailwindcss.com"></script>
  <script src="https://unpkg.com/react@18/umd/react.production.min.js"></script>
  <script src="https://unpkg.com/react-dom@18/umd/react-dom.production.min.js"></script>
  <script src="https://unpkg.com/@babel/standalone/babel.min.js"></script>
  <script src="https://unpkg.com/recharts@2.10.0/dist/Recharts.js"></script>

  <!-- 아이콘 처리: lucide-react 제거하고 텍스트/이모지로 대체 -->
</head>
<body>
  <div id="root"></div>
  <script type="text/babel">
    [JSX 코드]

    // 마지막 줄:
    ReactDOM.createRoot(document.getElementById('root')).render(<ComponentName />);
  </script>
</body>
</html>

===== lucide-react 아이콘 대체 방안 =====

lucide-react 아이콘은 다음 중 하나로 대체:
1. Emoji (이모지) - 가장 간단함
2. Unicode 기호 - 간단한 아이콘용
3. SVG inline - 정확한 렌더링 필요시
4. 텍스트 레이블 - 간단하고 효과적

예시:
- Sparkles → ✨ 또는 "⭐"
- Code2 → "📝" 또는 "💻"
- Brain → "🧠"
- Briefcase → "💼"
- Users → "👥"
- AlertTriangle → "⚠️"
- CheckCircle2 → "✅"
